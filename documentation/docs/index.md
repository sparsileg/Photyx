# Photyx Help

Welcome to the Photyx documentation.

Astrophotography sessions produce a lot of raw subs, and not all of
them are worth keeping. Photyx quickly sorts the good frames from the
bad — flagging the ones degraded by poor tracking, bad focus, or
passing clouds — so only your best subs move on to PixInsight, Siril,
or whatever you use for final processing. It also gives you a fast
quick-look stack along the way, so you can confirm a session was worth
the trouble before you commit to full processing.

Use the tutorials below to get started, or jump straight to the
Command Reference if you already know what you're looking for.
